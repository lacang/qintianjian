## 二、路径修改（共 9 处）

迁移前有 8 个脚本硬编码 `BASE = '/Coze/Drive/编程专家/论语思想单元候选库'`，换设备就断。

统一改为：

```python
# 路径一律相对本文件解析，不写机器绝对路径。

```

```python
APP = os.path.join(os.path.dirname(ROOT), '每日六爻', 'app', 'js', 'classic')
```

```python
REPO = os.path.dirname(os.path.dirname(ROOT))   # 仓库根：每日六爻/
APP = os.path.join(REPO, 'app', 'js', 'classic')
```
