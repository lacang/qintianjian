### 为什么 C 类为 0

C 类的定义是"两个同源载体同时缺字、无第三方传本、无独立注音证据"。这一批确实有几条是两载体同缺（VL-0033 成覸、VL-0034 飦粥、VL-0037/38 鶃鶃、VL-0045 瞷、VL-0132 有一个臣），但每一条都另有内部线索把性质定住了：

- **缺字位置有注文自注音义** → 可证注本用字，如 VL-0132 注文「?，古贺反，书作介」，说明缺的是「介」；

所以这些归 A 类（`ocr_defect`），不归 C 类。**C 类为 0 不是分类太松，是这批问题确实都有内部抓手。**

### 唯一的 P0：VL-0140

```
原典侧：极高明而中庸
注本侧：极高明而道中庸
```

「道」在这里是动词（由、行），"极高明而道中庸"意为"极尽高明而又行于中庸"。缺「道」字后，"极高明而中庸"变成两个并列形容词，句义从"境界+践行"退化为"境界的两个形容"，是《中庸》核心命题的实质性残缺。

这条同时是 B 类（需影印页确认刻本是否有「道」），**是本批唯一"高价值 + 需外部资料"的条目**。
