# 注疏层 B 类资料需求清单

生成日期：2026-11-04
对应批次：batch03（41–80 组全部 62 条）

## 说明

原分流把下列 9 个单元判为 B 类（"须查影印页"）。batch03 逐条复核后确认：这些条目在**电子文本内部**已有确定性证据（整段/整字缺失可定位、字形可直接对照、注文可自证），足以判定**差异性质**，因此已按 A 类标准回写 `error_source / diff_type / variant_scope`，`confirmed_scope` 统一为 `difference_nature`。

本清单记录的是**判完差异性质之后仍然悬着的问题**：刻本原貌、版本正确性、以及电子本缺陷究竟出在刻本还是数字化环节。这些问题电子文本内部无法回答，必须影印页。

判性质的结论不等于判版本的结论。本清单中每一条都保留"哪个版本对"为未决。

## 1. VG-051（工作单组 42）孟子集注·梁惠王章句下「公刘好货」章

**已判性质**：`ocr_defect / omission / 脱文`

**电子文本内部证据**：原典作「王曰：『寡人有疾，寡人好货。』对曰：『昔者公刘好货，《诗》云：乃积乃仓……』」；注本两载体同处作「王曰：『寡人有疾，寡人好货云：乃积乃仓……』」，缺「。』对曰：『昔者公刘好货，《诗》」共 14 字。注本其下注文「公刘，后稷之曾孙也。诗大雅公刘之篇」直接解释「公刘」与所引《诗》，证明朱注所见经文本来包含被缺失的这一整段。

**仍需影印本确认**：
- 刻本此处是否完整（即缺文是刻本就有，还是只发生在数字化环节）
- 刻本此处「对曰」前后引号与「诗云」的确切形式（关系到判缺文字数是否恰好 14 字）

**需要版本与位置**：《四书章句集注·孟子集注》卷第一下（梁惠王章句下），「王曰寡人有疾寡人好货」章。建议用中华书局 1983 年点校本（朱熹撰，以清嘉庆吴志忠校刻本为底）或上海古籍出版社影印宋当涂郡斋刻本，核对「寡人好货」至「乃积乃仓」之间。

**资料到位后的核校方法**：逐字比对刻本该处与电子本，确认缺文边界；若刻本完整而电子本缺，则本条 defect 位置落在数字化环节，可在 `source-defect-ledger.json` 另立一条 `kind=missing_passage` 记录（不改原始文件）。

## 2. VG-022（组 57）孟子集注·离娄章句下「齐人有一妻一妾」章

**已判性质**：`ocr_defect / omission / 脱文`

**电子文本内部证据**：原典作「吾将瞷良人之所之也」；注本两载体同处作「吾将良人之所之也」，「瞷」整字缺失。同章注文未对「瞷」作单独音义训释，本条不以注文自证，仅据缺口位置与句法结构判定（「吾将」后直接接名词短语，缺一动词）。

**仍需影印本确认**：
- 刻本此处是否作「瞷」
- 若刻本作「瞷」，则缺字发生在数字化环节；若刻本已有异（如作「闚」「窥」），则属传本异文，性质需改判

**需要版本与位置**：同上《孟子集注》卷第四下（离娄章句下），「齐人有一妻一妾而处室者」章，「其妻告其妾曰」段。

**资料到位后的核校方法**：核对刻本该字。这是本清单中**唯一可能推翻现有判定**的一条——因为原判定没有注文自证，只靠句法。

## 3. VG-075（组 59）论语集注·述而第七「亡而为有」章

**已判性质**：`textual_variant / char_level / 字词`

**电子文本内部证据**：原典作「……约而为泰，难乎有恒乎」；注本作「……难乎有恒矣」，句末虚词作「矣」。注本其下注文「凡若此者，必不能守其常也」不涉句末虚词，不能自证。

**仍需影印本确认**：
- 刻本句末作「乎」还是「矣」
- 这是**判版本正确性**的前提，不是判性质的前提

**需要版本与位置**：《论语集注》卷四（述而第七），「子曰圣人吾不得而见之矣」章末句。

**资料到位后的核校方法**：核对刻本虚词。若刻本作「矣」，则原典一系「乎」为传本异文；若刻本作「乎」，则注本电子本「矣」为录入异。两种情况都不改变「传本/用字差异」这一性质判定。

## 4. VG-045（组 60）论语集注·里仁第四「盖有之矣」章

**已判性质**：`textual_variant / char_level / 字词`

**电子文本内部证据**：原典作「盖有之矣，我未见也」；注本作「盖有之矣，我未之见也」，多一「之」字。注本注文两处均作「未之见」（「但我偶未之见耳」），与注本经文一致，说明注本一系确有「之」字。

**仍需影印本确认**：
- 刻本作「我未见也」还是「我未之见也」
- 注文「未之见」是否刻本原貌（若注文刻本作「未见」，则注文自证失效）

**需要版本与位置**：《论语集注》卷二（里仁第四），「子曰我未见好仁者」章末。

**资料到位后的核校方法**：同时核对经文与注文两处。经文与注文若在刻本中一致（都带「之」或都不带），则注本一系内部自洽，原典一系为传本异文。

## 5. VG-071（组 61）论语集注·里仁第四「事父母几谏」章

**已判性质**：`textual_variant / char_level / 字词`

**电子文本内部证据**：原典作「谏志不从」；注本作「见志不从」。注本注文先复述经文作「见志不从」，再引《内则》「谏若不入」作解释，二者用字不同，说明「见志」是注本经文、「谏若不入」是所引他书。

**仍需影印本确认**：
- 刻本作「见志不从」还是「谏志不从」
- 注文复述处刻本的确切用字（这是本条唯一的内部旁证，必须核实）

**需要版本与位置**：
1. 《论语集注》卷二（里仁第四），「子曰事父母几谏」章
2. 旁证：《礼记·内则》「父母有过，下气怡色柔声以谏；谏若不入，起敬起孝」段

**资料到位后的核校方法**：核对刻本经文与注文复述处是否同字。若同作「见」，则注本一系统一，原典「谏」为传本异文；若刻本经文作「谏」而注文复述作「见」，则注本自身已有参差，性质需降级为 `mixed`。
