# 注疏子集与索引

观心的第二层证据：原典之下，注疏之上。这里只放**内部检索与引用定位**用的注本子集，
不是产品内容源。产品要引注疏，必须走人工核实（见下文「检索命中 ≠ 证据成立」）。

## 一条命令重建

```bash
cd content/classics
python3 _build/fetch_commentary.py          # 下载 12 个注本，SHA256 校验
python3 _build/build_commentary_index.py    # 建索引
```

`fetch_commentary.py` 钉死殆知阁 commit `4a6d6f20`，master 变了也不会影响复现。
已存在的文件默认校验 SHA256，不符即失败（确需更新加 `--update`）。

## 检索命中 ≠ 证据成立

每条都带四个字段，产品侧必须据此判断能不能引用：

```json
"match_status": "hit",     // 自动召回只产出 hit
"verified_by": null,       // 人工核过才填
"verified_at": null,
"verify_note": null
```

状态机：`hit` → `candidate` → `verified`。**产品只能引用 `verified`。**
当前 9952 条全部是 `hit`，`verified_by` 全为空——索引刚建好，一条都还没人工核。

## align：对齐到什么程度

`align.status` 说明这条的经文与注文边界是怎么来的，直接决定它的可信度：

| status | 含义 | 能不能直接当证据 |
|---|---|---|
| `ok` | 用原典句子做锚，经文与注文已按原典切分 | 经文部分可用，注文仍需人核 |
| `self_contained` | 经文取自注本自身（注本把经文也抄了），未与原典交叉校验 | 需与原典比对后才能用 |
| `assumed` | 按排版交替规律（经文行/注文行）切分，未经校勘 | **不可**，只是定位辅助 |
| `no_canon` | 该经典尚未进 `parsed/canon`，只有章篇级挂靠，`canon_text` 为空 | **不可** |

当前分布：`self_contained` 6532、`ok` 2248、`assumed` 880、`no_canon` 292。

## 已知缺陷（已记录，未补齐）

结构上的脱漏一律记录不静默补齐：

- **王弼老子注**（藏外本）缺第 31、66、75 章，78/81。
- **老子道德经（晋王弼本）** 缺第 8、14、15、19、30、54、62、70、71、78 章，71/81。
- **庄子注（郭象）** 源文件只含内篇七篇，外篇杂篇缺失；且内篇内容整篇重复两遍，已去重保留一份。
- **南华真经注疏** 篇名有源文件讹字，如「渔父第三十」应为「第三十一」。
- **论语集注** 各篇有 15%~20% 小句未能在注本中定位（异文或分章差异），未命中的句子没有产出条目，不猜。
- **parsed/canon 缺 5 部原典**：老子、孟子、大学、中庸、庄子。这直接导致 5 个注本只能做章篇级挂靠。
