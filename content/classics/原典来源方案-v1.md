## 0. 一个必须先纠正的判断

上一轮我汇报「parsed/canon 缺 5 部原典」。复核后，这个说法**不准确**，必须改正。

查 `raw/SOURCES.json` 与 `raw/canon/*.json` 后的事实：

| 经典 | raw 数据 | 是否已在 raw/canon | 真实缺口 |
|---|---|---|---|
| 孟子 | `mengzi.json`，14 条，137757 字节 | **在** | 缺 `split_chapters.py` 的切分器 |
| 大学 | `daxue.json`，1 条，6796 字节 | **在** | 缺切分器 |
| 中庸 | `zhongyong.json`，1 条，13578 字节 | **在** | 缺切分器 |
| 老子 | 无 | **不在** | 真的缺数据 |
| 庄子 | 无 | **不在** | 真的缺数据 |

孟子、大学、中庸的数据来自 `gujilab/chinese-classical-corpus`（原 zi6me），与现有 5 部（论语、孝经、诗经、周易、礼记）**同一个数据集、同一许可 CC0-1.0、同一结构**：

```json
{"id": "mengzi#1", "source": "孟子", "chapter": "梁惠王上",
 "content": "孟子见梁惠王。王曰：「叟不远千里而来，亦将有以利吾国乎？」...",
 "author": "孟子", "era": "战国"}
```

`split_chapters.py` 的 `SPLITTERS` 只注册了 5 部：

```python
SPLITTERS = {
    'lunyu': ..., 'xiaojing': ..., 'shijing': ..., 'zhouyi': ..., 'liji': ...,
}
```

**所以「5 部缺失」实际上是「2 部缺数据 + 3 部缺切分器」。** 这个区别影响工作量判断，也影响许可判断——三部 CC0 数据不存在任何许可障碍，老子庄子的来源才有许可问题。

下文按「真缺数据的 2 部 + 已有数据的 3 部」分别作答。

## 1. 《孟子》

**① 原始数据来自哪里？**
`raw/canon/mengzi.json`，14 条记录，137757 字节，SHA256 `5880872fe0cd3e1489201b98e2e3f4f81273cc07c18670a258a06b8da06b6584`。上游 `gujilab/chinese-classical-corpus`，总集 12009 条 / 30 个来源 / SHA256 `41f2b610...5381`。

**② 具体是什么版本？**
数据集未标注底本，是现代整理本的白文，繁体/简体混排，含通行标点。与现有 5 部同源。

**③ 是否有明确许可？**
CC0-1.0，公有领域贡献，无署名义务、无传染性。与现有 5 部完全一致。

**④ 原文是否完整？**
14 条 = 十四卷，覆盖《孟子》七篇上下。**结构上是「一卷一条」，不是「一章一条」**——这是与论语（一篇一条、章内再切）不同的粒度。完整性可用「七篇十四卷 + 每卷字数区间」粗验，但不能用章数验。

**⑤ 章篇划分依据是什么？**
现有数据只有卷级 `chapter` 字段（如「梁惠王上」）。要做句子级对齐，需要在卷内按原典自然段或赵岐/朱熹的章次再切。**通行本《孟子》为 7 篇 14 卷 260 章（赵岐本 261 章）**，现有数据不含章号，切分器必须自行按「孟子曰」「孟子谓」等句式边界或朱熹《集注》章次切分——这是需要单独设计的部分。

**⑥ 是否存在异文？**
数据集内未标注异文。与 `mengzi-zhushu`（十三经注疏本）、`mengzi-jizhu`（朱熹集注本）比对时会遇到版本差异（如「梁惠王上」的「亦将有以利吾国乎」在部分本子作「亦将有以利吾国乎」），需在比对阶段记录，不预先假设一致。

**⑦ 能否与现有注本逐句交叉验证？**
**能，但要先解决章次问题**。现有两个注本 `mengzi-zhushu`（marked 型，有 `●卷一下·梁惠王章句上` 篇名行 + `[疏]` 标记）与 `mengzi-jizhu`（mixed 型，经文注文同行混排）。前者自带经文行，后者需要原典做锚。一旦切出章次，两个注本都可做句子级对齐。
**风险**：`mengzi-jizhu` 目前 0 条可用对齐（canon 缺），修好后预计能达到与 `lunyu-jizhu` 相当的水平（lunyu-jizhu 未命中率 21/122）。

## 2. 《大学》

**① 原始数据来自哪里？**
`raw/canon/daxue.json`，1 条，6796 字节，SHA256 `3d200644f2a08e87594595d299f2770736efe4bdb88e505f4cfdc34f86216428`。同 CC0 数据集。

**② 具体是什么版本？**
现代整理本白文。**关键问题：这是《礼记》第四十二篇的《大学》古本，还是朱熹《大学章句》的经传改本？** 数据集未标注。

**③ 是否有明确许可？**
CC0-1.0。

**④ 原文是否完整？**
1 条 = 整篇一条。字数 6796 字节（约 2200 汉字），与《大学》古本（约 1750 字）/ 朱子本（约 1750 字 + 补格物致知传 134 字）量级相符。

**⑤ 章篇划分依据是什么？**
**这是《大学》最麻烦的地方。** 三种分法互不兼容：
- 古本（《礼记》本）：不分章，一篇到底
- 朱熹《大学章句》：分「经」一章（205 字）+「传」十章（其中第五章格物致知传为朱子补）
- 现有注本 `daxue-zhangju-jizhu` 是朱熹本，**自带经传结构**

如果原典用古本、注本用朱子本，则「经传」边界无法对应；如果原典也按朱子本切，那等于用注本结构定义原典结构——**这正好触到「不得用注本自证」的红线**。

**⑥ 是否存在异文？**
古本与朱子本有实质差异：朱子把「《康诰》曰克明德」等段重排为传，并补「所谓致知在格物者」一段（134 字，非《大学》原文）。这是**结构性异文**，不是字词差异。

**⑦ 能否与现有注本逐句交叉验证？**
**只能部分验证，且必须声明口径。** 可行的做法：
- 原典用古本（CC0 数据，作为独立来源）
- 与 `daxue-zhangju-jizhu` 比对时，只比对**经文重叠部分**，明确标注「朱子本经传重排，古本无此结构」
- 朱子补传的 134 字**没有原典依据**，不得进入 canon，只能作为注本内容存在

**我的建议**：大学可以做，但 `align.status` 只能给 `ok`（经文重叠部分）和 `no_canon`（朱子补传部分），不做 `assumed`。

## 3. 《中庸》

**① 原始数据来自哪里？**
`raw/canon/zhongyong.json`，1 条，13578 字节，SHA256 `ddb688e14714376b8bd5bb65a9c898266ddd0f9c893cfe4c97fdc95d9bcdbf0b`。同 CC0 数据集。

**② 具体是什么版本？**
现代整理本白文。**《中庸》版本差异比《大学》小**——古本（《礼记》第三十一篇）与朱子《中庸章句》正文基本相同，朱子只是分章（33 章）并加注，没有补文。

**③ 是否有明确许可？**
CC0-1.0。

**④ 原文是否完整？**
1 条 = 整篇，约 3568 字，与通行本《中庸》字数相符。

**⑤ 章篇划分依据是什么？**
古本不分章；朱子分 33 章。**这里比《大学》好办**：33 章是朱子的阅读分层，不是文本改造，正文没有增删。因此可以：
- 原典保持整篇（CC0 数据原样）
- 与 `zhongyong-zhangju-jizhu` 比对时，用朱子的 33 章章首句作为分段锚
- 这个锚来自注本，但**只用于分段，不用于证明文本内容**——分段锚与内容验证是两件事，可以分开

**⑥ 是否存在异文？**
字词级异文存在（如「天命之谓性」各本一致，但「修道之谓教」后接「道也者不可须臾离也」的断句各家不同），无结构性差异。

**⑦ 能否与现有注本逐句交叉验证？**
**能，且是三部里最干净的。** 预计可达到与 `lunyu-jizhu` 相当的对齐率。

## 4. 《老子》

**这是本次调研的核心难点，也是唯一需要新增外部数据源的经典之一。**

### ① 原始数据来自哪里？

**候选 A：Kanripo（汉リポ / Kanseki Repository）KR5c0045《道德真經》**
- 仓库 `github.com/kanripo/KR5c0045`，分支 `ZTDZ`
- 3 个文件（`_000` 卷首、`_001` 卷上、`_002` 卷下），去标记后 7773 字符
- 京都大学人文科学研究所 CIEAS 项目，2013 年起建设，2016 年公开

**候选 B：殆知阁《道德经古本篇》** —— **已排除**，见 ⑥。

**候选 C：ctext `ctp:dao-de-jing`** —— **不可用**，`gettext` 取全文返回 `ERR_REQUIRES_AUTHENTICATION`，需 API key。

### ② 具体是什么版本？

**正统道藏本，河上公系统。** 证据：

1. 有河上公章名，逐章标注：`體道章第一`、`養身章第二`、`安民章第三`、`無源章第四`、`虛用章第五`、`成象章第六`……
2. 有章末字数统计：`右第三十二章七十一言`、`右第三十三章四十六言`、`右第三十七章四十九言篇上終`
3. 分卷上（1–37 章）/ 卷下（38–81 章），与河上公章句分卷一致
4. 卷首题 `道德眞經卷上`

Kanripo 的 `Readme.org` 标注：`HFL【正統道藏・涵芬樓版】`、`ZTDZ【正統道藏・三家本】`，`BASEEDITION HFL`、`WITNESS ZTDZ`。即**以涵芬楼影印本为底，三家本为校本**。

正文格式带影印页定位：`<md:KR5c0045_HFL_001-001a>` + `<pb:KR5c0045_SJB_001-110474b>`，`¶` 为分句标记。**可以逐行对照影印页**。

### ③ 是否有明确许可？

**CC BY-SA。** 官网页脚原文：

> (c) Kanseki Repository. 作成されたコンテンツは CC BY SA のライセンスで提供する。

项目论文（Wittern, *Next steps for the Kanseki Repository*, 2021）也写明设计目标：

> Providing reliable editions of premodern Chinese texts in a coherent and simple format **with a free license** was the main reason for starting the project.

**但这是一个必须让主人知道的风险**：现有 5 部 + 孟子/大学/中庸是 CC0（无约束），老子/庄子若用 Kanripo 则是 CC BY-SA（署名 + 相同方式共享）。混入后，整个 classics 数据集的对外分发可能需要按 CC BY-SA 处理。自用 PWA 不受影响，但将来若开源或商用，这是一个真实约束。

### ④ 原文是否完整？

**81 章完整，无缺章。** 验证方法与结果：

章界用双锚点：章首 `XX章第N`（河上公章名，覆盖 1–29、38–81 章共 73 章）+ 章末 `右第N章NN言`（覆盖 28–37 章）。两锚点并集后 **81 章连续、无缺号**。

字数分布：min 28 / max 144 / avg 72 / 总 5906 字（含河上公章名，纯正文约 5400 字，与通行本《老子》约 5162–5300 字相符）。

**章末字数统计可作独立完整性校验**，实测三章完全吻合：

| 章 | 实际字数 | 章末声明 |
|---|---|---|
| 第 30 章 | 79 | 七十九言 ✓ |
| 第 31 章 | 135 | 一百三十五言 ✓ |
| 第 32 章 | 71 | 七十一言 ✓ |

这是**古籍内部自校验**，比任何外部比对都硬。

### ⑤ 章篇划分依据是什么？

**河上公 81 章分章**，有章名、有章末字数。与通行本（王弼本）81 章**章次一一对应**——第 1 章「道可道非常道」、第 2 章「天下皆知美之为美」、第 3 章「不尚贤」、第 81 章「信言不美」，逐章核对一致。

**但章次对应 ≠ 文字一致。** 见 ⑥。

### ⑥ 是否存在异文？

**存在大量系统性异文。这是本部最关键的发现，直接决定能不能用。**

用 `laozi-wangbi-jin.txt`（四库全书本王弼注，经注交替，71 章有经文）逐章比对，剔除繁简差异后，**确认的真实异文**：

| 章 | Kanripo（道藏/河上公系统） | 王弼本 | 性质 |
|---|---|---|---|
| 13 | 何谓寵辱**寵为下** | 何谓宠辱**若惊**宠为下 | **脱文（脱「若惊」）** |
| 16 | 吾以观**其**复 | 吾以观复 | 衍文 |
| 18 | **智慧**出有大僞 | **慧智**出有大伪 | 语序 |
| 22 | **弊**則新 | **敝**则新 | 异体/异文 |
| 24 | **跂**者不立 | **企**者不立 | 异文 |
| 26 | **君子**終日行 | **圣人**终日行 | 异文 |
| 27 | 善**計**不用籌策 | 善**数**不用筹策 | 异文 |
| 31 | 夫**美**兵者不祥之器 | 夫**佳**兵者不祥之器 | 异文 |
| 32 | **王侯**若能守 | **侯王**若能守 | 语序 |
| 33 | 知人者智**也** | 知人者智 | 衍文 |
| 35 | 安**乎泰** | 安**平太** | 异文 |
| 36 | 將欲**翕**之 | 将欲**歙**之 | 异文 |
| 40 | 天下**之**物生于有 | 天下万物生于有 | 衍文 |
| 43 | 無有入**于**無間 | 無有入無间 | 衍文 |
| 72 | 無**狹**其所居 | 無**狎**其所居 | 异文 |
| 74 | **民常**不畏死 | **民**不畏死 | 衍文 |
| 76 | **民**之生也柔弱 | **人**之生也柔弱 | 异文 |
| 77 | 天之道其猶張弓**乎** | 天之道其犹张弓**与** | 异文 |

**这不是「版本不同所以字不同」的小问题。** 第 13 章脱「若惊」二字、第 76 章「民之生」对「人之生」，都是会影响释义的实质差异。

**所以：Kanripo 道德真經不能直接当作「王弼本老子原典」使用。** 它是河上公系统的道藏本。用它去对齐 `laozi-wangbi` / `laozi-wangbi-jin`（王弼注本），会产生系统性错配。

**已排除的方案**：
- **殆知阁《道德经古本篇》**：只有 79 章，缺第 44、78 章；且傅奕本章次与通行本不同，无法与王弼注逐章对应。**不合格。**
- **用 `laozi-wangbi-jin` 自带的经文当原典**：违反「不得用注本自证」铁律。**明确不做。**

### ⑦ 能否与现有注本逐句交叉验证？

**部分能，且必须带异文标注。**

- 对 `laozi-wangbi-daozang`（正统道藏本，经注交替）：**同系统，可逐句对齐**，预期质量最高
- 对 `laozi-wangbi-jin`（四库本王弼注）：章次可对应，但上述 18 处异文会导致句子级匹配失败。需要「容异文匹配」策略 + `variant` 标注
- 对 `laozi-wangbi`（王弼注，只有注文无经文）：只能做章级挂靠，无法句子级对齐

**这正好印证了主人的提醒**：「不能因为有 81 章，就默认所有版本都能与 81 章逐章对应。」实测结论是：**章次能对应，文字不能直接对应**。

## 5. 《庄子》

### ① 原始数据来自哪里？

**Kanripo KR5c0051《南華真經》**，分支 `ZTDZ`（白文本），5 个文件（`_000`–`_004`），去标记后 75283 字符。

**同一仓库的 `master` 分支是另一个东西**：11 个文件（`_000`–`_010`），10 卷，202097 字符，**是郭象注本 + 陆德明音义**（卷首题 `南華眞經卷第一 郭象子玄註 陸德明音義`）。这是重要副产品，见 ⑦。

**已排除**：殆知阁《南华真经.txt》（OCR 讹字严重，见 ⑥）；ctext `ctp:zhuangzi`（需 API key）。

### ② 具体是什么版本？

**正统道藏白文本**，`BASEEDITION HFL`（涵芬樓版）+ `WITNESS ZTDZ`（三家本），`Readme.org` 另标 `SBCK【四部叢刊】` 作校本。

**是白文，不含注。** 这一点很重要——它满足「独立原典」要求。

### ③ 是否有明确许可？

CC BY-SA，同老子（同一项目、同一站点声明）。

### ④ 原文是否完整？

**33 篇完整：内篇 7 + 外篇 15 + 杂篇 11。** 逐篇验证：

| 类别 | 篇数 | 篇名 |
|---|---|---|
| 内篇 | 7 | 逍遥遊、齊物論、養生主、人間世、德充符、大宗師、應帝王 |
| 外篇 | 15 | 駢拇、馬蹄、胠篋、在宥、天地、天道、天運、刻意、繕性、秋水、至樂、達生、山木、田子方、知北遊 |
| 杂篇 | 11 | 庚桑楚、徐無鬼、則陽、外物、寓言、讓王、盜跖、說剱、漁父、列御寇、天下 |

**总字数 65103 字**，与通行本《庄子》约 65000 字相符。每篇首句均正确（北冥有魚、南郭子綦隱几而坐、吾生也有涯、顔回見仲尼請行……）。

**这直接回应了主人的提醒**：「不能拿郭象注本的七篇内篇结构，冒充完整三十三篇注疏。」——Kanripo 白文本是完整 33 篇，不是内篇七篇。

### ⑤ 章篇划分依据是什么？

**按篇分（33 篇），篇名行格式统一**：

```
　　　内篇逍遥遊第一¶
　　　内篇齊物論第二¶
　　...
　　　外篇駢拇第八¶
　　...
　　　雜篇天下第三十三¶
```

篇内不分章（《庄子》传统也不按章分，只按篇）。篇名用字有异体：`逍遥遊`（通行作「逍遙遊」）、`說剱`（「說劍」）、`列御寇`（「列禦寇」）、`内篇`/`內篇` 混用。

### ⑥ 是否存在异文？

**与注本比对的篇名异文**：

| Kanripo | nanhua-zhushu | 说明 |
|---|---|---|
| 逍遥遊 | 逍遥游 | 遊/游 |
| 駢拇 | 骈姆 | 拇/姆（注本讹） |
| 胠篋 | 朕筐 | 注本 OCR 讹字 |

## 6. 待裁决的三个问题

### 裁决一：CC BY-SA 许可能否接受？

老子、庄子的唯一合格来源（Kanripo）是 **CC BY-SA**，不是 CC0。后果：
- 自用 PWA：无影响
- 将来开源 / 商用：整个 classics 数据集可能需要按 CC BY-SA 分发，且必须署名 Kanseki Repository

**可选路径**：
- A. 接受 CC BY-SA，在 `SOURCES.json` 里逐文件记录许可与署名要求，产品内做来源标注
- B. 老子、庄子继续标缺失，不引入 CC BY-SA 数据
- C. 先只引入庄子（33 篇完整、质量高、价值大），老子继续缺

### 裁决二：《老子》的异文怎么处理？

Kanripo 道德真經是**河上公系统**，与王弼注本有 18 处已确认异文（含第 13 章脱「若惊」）。

**可选路径**：
- A. 作为「道藏本原典」引入，新增 `align.status = "ok_variant"`，每条记录 `variant_note` 列出与王弼本的差异。对 `laozi-wangbi-daozang`（同系统）正常对齐，对 `laozi-wangbi` / `laozi-wangbi-jin`（王弼系统）标注异文、不做强匹配
- B. 引入但只用于 `laozi-wangbi-daozang` 一个注本，王弼两个注本继续标 `no_canon`
- C. 老子继续标缺失

**我的倾向：A。** 理由：河上公系统的道藏本本身就是一个真实存在的《老子》版本，它不是「错误的王弼本」，而是「另一个传本」。把它标注清楚，比假装没有更有价值。但 `verified_by` 必须保持空——**异文标注是「已知差异」，不是「已核实」**。

### 裁决三：《大学》的经传结构怎么定？

朱熹《大学章句》把《大学》重排为「经一章 + 传十章」，并补了 134 字的格物致知传。如果原典用古本、注本用朱子本：
- 经文重叠部分可对齐
- 朱子补传 134 字**无原典依据**，只能作为注本内容
- 「经传」边界不能由注本定义原典

**可选路径**：
- A. 原典用古本，注本比对时明确标注「朱子本经传重排，古本无此结构」，朱子补传部分标 `no_canon`
- B. 大学不做原典，继续标缺失

**我的倾向：A**，但必须在 `align` 里显式记录 `structure_note`。
