# 原典误引、改写及争议内容清单

---

## 一、常见误引/张冠李戴/断章取义/现代改写

### 1.「以德报怨」——最大的误读

| 项目 | 内容 |
|------|------|
| **流行说法** | "以德报怨"是孔子主张的处世态度，意为用恩惠回报怨恨 |
| **原文实际出处** | 《论语·宪问》第34章："或曰：'以德报怨，何如？'子曰：'何以报德？以直报怨，以德报德。'" |
| **差异性质** | **严重误读**。原文中"以德报怨"只是别人的提问（"有人问孔子：用恩德来报答怨恨，怎么样？"），孔子的回答是**反对**——他反问"那用什么报答恩德呢？"并明确提出"以直报怨"。**孔子明确否定了"以德报怨"** |
| **来源** | [(央视新闻)](http://m.news.cctv.com/2018/09/28/ARTIo47hUK2tZNNzP9lIUW5E180928.shtml)；[(光明网)](https://news.gmw.cn/2022-03/07/content_35567055.htm) |

### 2.「三十而立」——世俗化改写

| 项目 | 内容 |
|------|------|
| **流行说法** | 三十岁要成家立业、买房立足 |
| **原文** | 《论语·为政》第4章："三十而立" |
| **差异性质** | **语义改写**。"立"在《论语》中有明确含义——"立于礼"（《泰伯》）、"不知礼无以立也"（《尧曰》），指懂得"礼"、言行得当、人格独立。与"买房""成家"无直接关系 |
| **来源** | [(中山日报/刘强讲座)](https://zsrbapp.zsnews.cn/mobile/news/viewNews/2/746950) |

### 3.「言必信，行必果」——断章取义导致褒贬颠倒

| 项目 | 内容 |
|------|------|
| **流行说法** | 说话算话、做事果断，是对人"靠谱"的最高评价 |
| **原文** | 《论语·子路》第20章："言必信，行必果，硁硁然小人哉！" |
| **差异性质** | **褒贬颠倒**。原文中孔子说的是：一味死守诺言、不懂审时度势，这只是浅薄固执的庸人罢了！在《论语》语境中，这不是褒义而是贬义。孟子亦云"大人者，言不必信，行不必果，惟义所在" |
| **来源** | [(今日头条)](http://m.toutiao.com/group/7642477909357117962/)；[(中山日报/刘强讲座)](https://zsrbapp.zsnews.cn/mobile/news/viewNews/2/746950) |

### 4.「愚不可及」——语义完全翻转

| 项目 | 内容 |
|------|------|
| **流行说法** | 形容一个人愚蠢到了极点 |
| **原文** | 《论语·公冶长》第17章："子曰：'宁武子邦有道则知，邦无道则愚；其知可及也，其愚不可及也。'" |
| **差异性质** | **语义翻转**。孔子是在**称赞**宁武子：世道好时展现才智，世道差时装傻——"他那种聪明别人能做到，但他那种装傻的境界别人做不到"。"愚不可及"原意是"装傻的境界无人能及"，是极高的赞美 |
| **来源** | [(央视新闻)](http://m.news.cctv.com/2018/09/28/ARTIo47hUK2tZNNzP9lIUW5E180928.shtml) |

### 5.「老而不死，是为贼」——断章取义

| 项目 | 内容 |
|------|------|
| **流行说法** | 老年人是祸害/没用的人 |
| **原文** | 《论语·宪问》第46章："幼而不孙弟，长而无述焉，老而不死，是为贼。" |
| **差异性质** | **断章取义**。完整语境是孔子批评一个人：年少时不孝不悌，长大后没有成就，老了还不死——这样的人是祸害。孔子并非对老年人的一般性贬低 |
| **来源** | [(今日头条)](http://m.toutiao.com/group/7642477909357117962/) |

### 6.「学而优则仕」——语义倒置

| 项目 | 内容 |
|------|------|
| **流行说法** | 学习优秀就去做官 |
| **原文** | 《论语·子张》第13章："子夏曰：'仕而优则学，学而优则仕。'" |
| **差异性质** | **语义倒置**。"优"指"有余力"而非"优秀"。原意是：做官有余力就去学习，学习有余力就去做官。是学习与政务的互补关系，非"成绩好就当官"的选拔逻辑。且此句为子夏所言，非孔子原话 |
| **来源** | [(央视新闻)](http://m.news.cctv.com/2018/09/28/ARTIo47hUK2tZNNzP9lIUW5E180928.shtml) |

### 7.「民可使由之，不可使知之」——句读之争

| 项目 | 内容 |
|------|------|
| **流行说法** | 老百姓只要照做就行，不需要让他们明白道理。被视为孔子"愚民"思想的证据 |
| **原文** | 《论语·泰伯》第9章："民可使由之，不可使知之。" |
| **差异性质** | **句读争议**。传统句读如上。但有学者主张重新断句为"民可，使由之；不可，使知之"（百姓认可，就让他们去做；不认可，就让他们明白道理）。原文无标点，句读不同则含义完全相反 |
| **来源** | [(今日头条)](http://m.toutiao.com/group/7642477909357117962/) |

### 8.「小不忍则乱大谋」——"忍"字误读

| 项目 | 内容 |
|------|------|
| **流行说法** | 小事不忍耐就会坏了大事 |
| **原文** | 《论语·卫灵公》第27章："巧言乱德，小不忍，则乱大谋。" |
| **差异性质** | **词义误读**。学者考证，在《论语》时代至汉代，"忍"不带宾语且受否定时，通常表示"忍心"而非"忍耐"。所以"小不忍"可能指"在小事上不忍心（心太软）"，而非"在小事上不能忍耐" |
| **来源** | [(今日头条)](http://m.toutiao.com/group/7642477909357117962/) |

### 9.「君子固穷」——"固"字误读

| 项目 | 内容 |
|------|------|
| **流行说法** | 君子安于贫穷 |
| **原文** | 《论语·卫灵公》第2章："君子固穷，小人穷，斯滥矣。" |
| **差异性质** | **词义误读**。"固"在此处为副词"固然"，非"固守"。原意为"君子固然也有困顿的时候（但不像小人那样一困顿就胡作非为）"。孔子并不反对追求富贵——《述而》中他说"富而可求也，虽执鞭之士，吾亦为之" |
| **来源** | [(今日头条)](http://m.toutiao.com/group/7642477909357117962/) |

## 二、版本与注家分歧条目

### 1.「学而时习之」的"时"与"习"

| 注家 | 解释 | 要点 |
|------|------|------|
| 王肃（《论语集解》引） | "时者，学者以时诵习之" | "时"为"以时"（在适当时候），非"时常" |
| 朱熹《论语集注》 | "既学而又时时习之"；"习，鸟数飞也" | "时"为"时时"，"习"为反复实践（不限于读书） |
| 杨伯峻《论语译注》 | "按一定的时间去实习它" | 认为周秦古书中"时"作副词时多为"在一定时候"，朱熹以后代词义释古书 |
| 李泽厚《论语今读》 | "学习而经常实践" | 强调"实践"维度 |
| **分歧性质** | **训诂分歧**——对"时""习"二字的词义理解因时代不同而有差异 |

### 2.「以直报怨」的"直"

| 注家/学者 | 解释 | 要点 |
|------|------|------|
| 皇侃《论语义疏》 | "用直道报之" | 直=正道 |
| 朱熹《集注》 | "爱憎取舍，一以至公而无私" | 直=至公无私 |
| 杨伯峻 | "拿公平正直来回答怨恨" | 直=正直 |
| 刘笑敢 | "以牙还牙以眼还眼" | 直=值=对等 |
| 李零 | "应读为值" | 同上 |
| 张明辉（光明网2022） | "对等复仇，不因怨恨而加重报复" | 以出土秦简为佐证 |
| 反驳者（光明网2022） | "怨"在《论语》中均为"怨恨"非"仇怨"，抽象概念无法"对等" | 认为"直"仍应理解为"正直/直道" |
| **分歧性质** | **训诂+义理分歧**——涉及古义考证和伦理立场 |

### 3.「克己复礼」的"己"

| 注家 | 解释 | 要点 |
|------|------|------|
| 朱熹 | "己，谓身之私欲也" | 己=私欲，克=战胜 |
| 传统汉学 | 己=自身，克=约束/修炼 | 克己=约束自身，非消灭私欲 |
| **分歧性质** | **哲学体系分歧**——朱熹将《论语》纳入理学体系（天理/人欲），与汉学训诂传统不同 |

### 4.「孝弟也者，其为仁之本与」——"为仁"还是"是仁"

| 注家 | 解释 | 要点 |
|------|------|------|
| 一般理解 | 孝悌是仁的根本 | 将"为"理解为"是" |
| 朱熹/程颐 | "为仁，犹曰行仁"；"谓之行仁之本则可，谓是仁之本则不可" | 孝悌是"实践仁"的起点，不是仁的本体（因仁是性，性中只有仁义礼智，曷尝有孝悌来） |
| 黄宗羲批评 | 程朱之说"乃先名而后实" | 认为朱熹将孝悌架空，视人伦日用为本 |
| **分歧性质** | **义理分歧**——涉及"仁"的本体论定位 |

### 5.「中庸」——至高德行vs折中妥协

| 理解 | 内容 |
|------|------|
| 《论语》原意 | "中庸之为德也，其至矣乎"——孔子视中庸为最高德行 |
| 大众理解 | 折中、妥协、和稀泥、不偏不倚的平庸之道 |
| 学术界 | "执两用中"——在对立两端中找到最适宜的平衡点，非简单取中间值 |
| **分歧性质** | **概念退化**——一个哲学概念在世俗化过程中被严重简化 |

## 四、说明

本清单所列误引均经过原典核验。每条误引的差异性质分为：
- **严重误读**：意思完全相反（如"以德报怨"）
- **语义改写**：原义被世俗化替换（如"三十而立"）
- **断章取义**：截取部分导致含义改变（如"言必信行必果"）
- **词义变迁**：古今词义不同导致误读（如"愚不可及""君子固穷"）
- **句读争议**：因古文无标点导致不同理解（如"民可使由之"）
