## 列含义（v2-full-matrix.csv）

- month：实验月令地支；mask：0–4095 编码六爻值（每两位对应一爻，6/7/8/9）；bengua/biangua：主卦/变卦名；
  domain：问事域；yongShi：引擎选中用神是否持世（1/0）。
- `<方案>Score/<方案>Level`：该方案对同一盘的总分与档位（2 大吉 / 1 吉 / 0 平 / -1 凶 / -2 大凶）。
- vallCut：vall 实际被并（置 0）的信号 sid，多个用 `|` 分隔。sid→规则：
  shiwang/shishuai 世爻月建旺衰(235/236)、shihuike/shihuisheng 世爻回头克/生通用(237/238)、
  liuchonggua/liuhegua 卦象(310/311)。（health 专项被并的是通用侧，cut 中同样记 shihuike/shihuisheng。）

## 如何回溯任意一条

1. 用 mask 复现六爻：`vals[i]=[6,7,8,9][(mask>>(i*2))&3]`，以固定参数 paipan 得主/变卦；
2. 取该行 month 作为实验月令（日辰固定酉），对 domain 跑 `judgeNajia`，即得 orig 全部信号与分数；
3. vallScore 与 origScore 之差等于 vallCut 所列 sid 权重之和，可手工核对。

复算命令：
```
node tools/score-verify-v2/scripts/run-v2.mjs      # 重跑全矩阵
node tools/score-verify-v2/scripts/breakdown.mjs   # 生成分域/分月/戌月差异
```
