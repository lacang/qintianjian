## 一、古籍溯源与呈现（透明度类，源自审计 #6/#8/#9）

1. **典籍库溯源缺口**：结论卡引用的《四时旺相章》《世应章》等部分篇目，不在站点内置 reading 典籍库中，UI 却称"都可回到这里核对"。应让每条引用都能链接到库内原文，或对库内没有的篇目明确标注"未收录原文"。
2. **原文 vs 要旨未在 UI 区分**：verdict.js 规则库已用 `gu`（原文/通行口诀）与 `hua`（白话）分开，且对不能逐字确证者内部标注"要旨"；但前端展示未把"逐字原文"和"通行要旨转述"视觉区分开。
3. **部分 sid 降级只显书名**：如 `liuchong` 在 RULES 无独立条目时只显示《六冲章》书名，无原文白话。补条目或显式降级说明。
4. 边界：规则库自身已声明"凡字句不能逐字确证者不硬造逐字引文"——这一诚实底线应保留，补溯源时不得为补齐而编造原文。
