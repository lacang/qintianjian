   不存在「日破扣 5 分」。Δ-5 / Δ-7 是月破失气等多项规则的叠加结果。

三、权重逐项拆解（回答「Δ-5 不等于日破扣 5 分」）
────────────────────────────────────────────────────────────────────────
撤销单因素后的总分贡献分布（full.score − 变体.score）：

  日破新增    -1 分 × 141
  月破失气    -5 分 × 77 ｜ -7 分 × 29 ｜ 0 分 × 35
  六合名单    -1 分 × 24 ｜ -2 分 × 10 ｜ +1 分 × 1 ｜ 0 分 × 106
  六冲名单    -2 分 ×  2 ｜ 0 分 × 139

规则级 Δw 拆解：

  撤销日破
     141 条  Δw = { ribo: -1 }

  撤销月破失气
      77 条  Δw = { wangxiang: -3, ribo: -1, andong: -1 }          → 合计 -5
      29 条  Δw = { wangxiang: -3, ribo: -1, shituo: -2, andong: -1 } → 合计 -7
      35 条  Δw = { }（无规则权重变化）

  撤销六合名单
      24 条  Δw = { liuhunhun: -1 }
      10 条  Δw = { liuhunhun: -2 }
       1 条  Δw = { liuhunhun: +1 }
     106 条  Δw = { }

  撤销六冲名单
       2 条  Δw = { liuhunhun: -2 }
     139 条  Δw = { }

规则身份说明：
  wangxiang  = 四时旺相章，爻在本月令下的旺衰分（旺→休，差 -3）
  andong     = 暗动章，静爻旺相被日冲 +2；旺被压为休后该 +2 消失
  ribo       = 日破章，静爻休态被日冲 -1
  shituo     = 卜筮正宗·黄金策·失脱，仅 lost 域财爻规则
  liuhunhun  = 增删卜易·婚姻章，六合 +1 / 六冲 -1 / 六合变六冲 -2

核心结论：日破在全部 141 条中都只贡献 -1 分。
Δ-5 = 旺衰失气 -3 + 暗动消失 -1 + 日破 -1。
Δ-7 = 上式 + 失脱章财爻 -2。
Δ-2 = 六合 -1 + 日破 -1。
没有任何一条把 5 分或 7 分归给日破。

五、重复惩罚检查
────────────────────────────────────────────────────────────────────────
1. anDong 与 riPo 互斥性
   同一爻不可能同时为真（本批全量检查 56,623,104 次，共现 0 次）。
   故「暗动 +2 消失」与「日破 -1 出现」不是同一爻的两次扣分，
   而是休/旺状态归类切换的两个互斥分支，不构成重复惩罚。

2. 月破相关叠加（需董事长裁决，本批未改）
   - yuepo -3：用神被月建相冲（既有 v121 规则，PRE/POST 两侧均计）

   反事实 Δw 中未出现 yuepo，说明该 -3 在修复前后均计分，
   本轮新增的只有 wangxiang 的旺衰变化 -3。
   但两条依据同源于「月建相冲」，是否构成同一古法依据两处计分，
   请董事长裁决。

3. shituo -2 仅出现在 lost 域 29 条，是失脱章对财爻旺衰的独立规则，
   与日破 / 月破无重复。

   但影响的是不同卦（本卦 vs 变卦），不是同一判断的两次计分。
