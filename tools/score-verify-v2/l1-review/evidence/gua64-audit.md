# 64 卦六冲 / 六合 独立核对表

**独立性**：六冲/六合由本脚本手写京房纳甲表（纳甲口诀，独立于任何代码数据）+
古法「三对爻全冲/全合」定义推导，不读取代码名单；再与名单、specialType、verdict 实测三方对照。

**概念区分**：「卦体分类」= 整卦三对爻是否全冲/全合；「世应关系」= 世支与应支是否冲/合。
两者独立：世应相冲不等于卦体六冲（例如 46 个普通卦中多卦世应相冲/相合）。

| verdict 触发是否符合「在名单 && 闸门未抑制」 | 64 卦全部一致 ✅ |
| 变卦走向规则（六冲变六合/六合变六冲）枚举 64×63 | 全部一致 ✅（命中 160 例） |

> **重要实际行为**：love 域本卦六冲 −1 / 六合 +1 两条规则带 V2 去重闸门
> （六冲需 `!世应相冲`、六合需 `!世应相合`）。由上表两行可知：六冲卦世应必然相冲、
> 六合卦世应必然相合，因此这两条规则对「真正的六冲/六合卦」**恒不触发**（死代码），
> 其效果由世应相冲 −2 / 相合 +1 承担。名单修正对 love 的实际影响只通过「变卦走向」
> 规则（+2/−2，无闸门）体现；对 people 行人六冲（无闸门）直接体现。
