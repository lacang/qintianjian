**1 个失败案例（FAIL-L0-01）：**

```
用例编号：G0078
分类：T2 魂卦标记
输入：雷火丰（二进制 101 100，自下而上；即下卦离 101、上卦震 100）

预期（独立构造）：
  { guaXu: 6, isYouHun: false, isGuiHun: false, isBaChun: false }
  依据：八宫变爻规则 —— 坎宫第六卦 = 五世卦，不是归魂（归魂必须是第八卦）

实际（paipan 输出）：
  { guaXu: 6, isYouHun: false, isGuiHun: true, isBaChun: false }

差异字段：isGuiHun  false → true

根因：constants.ts 的 GUI_HUN_OVERRIDE 主动把雷火丰标为归魂（对齐主人现用 App），
      但未同步修改世应（仍为五世：shiPosition=5, yingPosition=2）
      → 归魂（世3）与五世（世5）在古法内部不能并存

复现命令：
  cd /Coze/Drive/编程专家/每日六爻
  node -e "
  import('./liuyao-core/dist/index.js').then(m=>{
    const p=m.paipan({yaoValues:[7,8,7,8,7,8],year:2026,month:10,day:27,hour:10,minute:38,gender:1,question:''});
    console.log(p.benGua.name, 'guaXu=',p.benGua.guaXu, 'shi=',p.benGua.shiPosition, 'isGuiHun=',p.benGua.isGuiHun);
  })"
  # 输出：雷火丰 guaXu= 6 shi= 5 isGuiHun= true

影响面：计算层无错（世应数值、纳甲、六亲全对）；verdict.js 不使用 isGuiHun → 不影响吉凶；
        影响盘面头部标签文案（用户可见）+ 用户对"归魂卦"的认知
登记：ISSUE-L0-001
```

## 5. 结论

- **计算层（历法 + 排盘事实）0 真实错误**：4541 个用例里，计算层的差异只有雷火丰的主动覆盖（1 例），且它是设计选择而非算错
- **展示层 1 个真实缺陷**：藏爻阴阳（4 宫），影响 32 卦、仅"显示藏爻"时可见、不影响吉凶
- **1 个需裁定的矛盾**：雷火丰「归魂 + 世五」
- 其余全部为流派差异或设计选择，已登记为 F6
