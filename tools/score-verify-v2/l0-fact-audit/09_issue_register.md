## 分级定义

| 级 | 名称 | 含义 |
|---|---|---|

## ISSUE-L0-001 雷火丰「归魂」标签与「五世」世位自相矛盾

| 字段 | 内容 |
|---|---|
| **1 编号** | ISSUE-L0-001 |
| **2 标题** | 雷火丰被标「归魂」但世位仍是「五世」 |
| **3 分级** | F1（卦象结构）+ F6（流派差异） |
| **4 现象** | 盘面显示「坎宫：雷火丰（归魂）」，但世爻在第 5 位、应爻在第 2 位。古法归魂卦 = 八宫第八卦 = 世三应六。雷火丰是坎宫第六卦（五世），二者不能并存。 |
| **5 证据** | ① `liuyao-core/src/constants.ts` `GUI_HUN_OVERRIDE` 注释原文；② 用例 G0078（`output/02_gua_paipan.json` failures）；③ 用例 U60001（`output/03_ui.json` failures）；④ 《增删卜易·归魂游魂章》底本行 976：「归魂卦为各宫之第八卦」 |
| **6 影响范围** | 1 个卦（雷火丰）。不影响：世应数值、纳甲、六亲、旬空、旺衰、**吉凶评分**（`verdict.js` 不使用 `isGuiHun`，已 grep 确认）。影响：盘面头部标签文案、用户对"这是归魂卦"的认知（可能自行套用归魂断法） |
| **7 严重度** | 中 —— 矛盾肉眼可见，但不产生计算错误、不影响结论 |
| **8 复现方式** | 见 08 文档 §2.2 的 `node -e` 命令，输出 `坎宫：雷火丰（归魂） 世5应2` |
| **9 根因** | 项目为对齐主人现用「六爻排盘」App，只覆盖了魂卦标记（`isGuiHun: true`），没有覆盖世应（因为改世应会连带影响整个八宫结构与后续所有规则）。结果是"半截覆盖" |
| **10 是否阻塞发版** | 否。属既有状态（非本轮引入），不影响计算与吉凶 |
| **11 建议** | 三个方案，见 10 文档 §2。倾向：**要么全取 App 口径（归魂 + 世三），要么全不取（五世 + 不标归魂）**，不要半截 |
| **12 责任层** | 主人裁定（涉及"以哪个体系为金标准"的取向问题，不是技术对错） |

## ISSUE-L0-004 天机起卦四象均匀 → 动爻率 50%

| 字段 | 内容 |
|---|---|
| **1 编号** | ISSUE-L0-004 |
| **2 标题** | 天机起卦每爻四象各 25%，动爻率 50%，是真实摇钱（25%）的两倍 |
| **3 分级** | F6（设计差异） |
| **4 现象** | 单爻动概率：真实摇钱 25%（老阴 1/8 + 老阳 1/8）；天机 50%（6/7/8/9 各 25%）。6 爻全静概率：真实 17.8%；天机 1.56%。出现变卦的概率：真实 82.2%；天机 98.4% |
| **5 证据** | `liuyao-core/src/input.ts:castTianji` 注释原文："每爻先按四象均匀（6/7/8/9 各 25%）。调用方若希望限制动爻数可自行重投，本函数不做人为干预（金标准未限定天机起卦的动爻概率分布，均匀最中立）" |
| **6 影响范围** | 所有用天机起卦的盘。直接影响 `verdict.js` 中所有依赖"变卦"的规则触发频率（六冲变六合 +2、六合变六冲 −2、用神化回头克、化墓、化绝等） |
| **7 严重度** | 中 —— 不产生错误，但让"天机起卦"与"摇钱起卦"的盘面统计特性显著不同，同一个人同一件事用两种方式起卦，得到变卦类凶象的概率差约 1.2 倍 |
| **8 复现方式** | 理论计算 + 代码审查；`castTianji` 用 mulberry32 均匀采样 |
| **9 根因** | 注释明示是主动选择（"均匀最中立"） |
| **10 是否阻塞发版** | 否 |
| **11 建议** | 若希望两种起卦方式可比，把 `castTianji` 改为按背数二项分布采样（`backs = 三枚硬币 1/2 相加`），即可与 `castCoins` 概率一致。改动约 5 行。**但这是产品取向问题，需主人决定** |
| **12 责任层** | 主人裁定 |
