# 05 · L1 实施优先级

排序依据三条：**错误风险 × 影响面 × 测试可行性**。
不含"看起来重要但本轮不该动"的项。

## 第三批：暂缓（需要新实现，工作量大，影响面待评估）

| # | 项 | 暂缓理由 |
|---|---|---|
| 1 | 动爻被日冲「散」（12288 爻次） | 需新增标记 + 决定权重，且古法对"散"的吉凶方向有分歧（散即无用 vs 冲散反成） |
| 2 | 动而化墓（12288 爻次） | 需新增标记；与"动爻自身入墓"（79872）的关系需先理清层级 |
| 3 | 变爻自身旬空/月破（化空 24576、化破 12288） | 需扩展 `YaoState` 数据结构（加变爻状态载体），属接口变更，影响所有消费方 |
| 4 | 三合局 | 有表无逻辑。三合局成立条件（三支俱全？含动爻？含日辰？）流派分歧大 |
| 5 | 三刑 / 六害 | 同上，且古法中权重较低，是否值得纳入评分存疑 |
| 6 | 出空 / 实破 / 逢合 的结构化时点 | 需新建应期计算模块，属新功能而非修缺陷 |

## 实施顺序的依赖关系

```
P1-1 ─┐
P1-2 ─┼→ 需要 score-regression 基线 → 才能量化改动影响
P1-3 ─┘

P2-4（门禁接入）← 必须先有 verify-facts --check
                ← 且 P1-1/P1-2/P1-3 修完才有意义（否则接入即红）

P2-1 / P2-2 / P2-3 ← 都需先定口径，否则改完仍不可信
```

**关键判断：先把"确定的错"修掉（P1），再把"可信的核对"接进门禁（P2-4），最后才动口径未定的项（P2-1~P2-3）。** 顺序颠倒会导致：门禁接入时一堆已知失败，反而被迫放宽门禁。
