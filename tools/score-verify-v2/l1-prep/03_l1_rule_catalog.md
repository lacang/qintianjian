# 03 · L1 规则目录与证据来源

说明：本目录用于**盘点**，不意味着所有项目都要在本轮一次完成。
每条给出：规则定义 / 古籍来源 / 实现位置 / 当前状态 / 证据 / 待定项。

状态标记：
- `已实现·有独立证据` —— 有不由被测代码生成的预期，且核对通过
- `已实现·证据不足` —— 有代码，测试薄弱
- `已实现·有缺陷` —— 有代码，但已知与古法或自身其他部分矛盾
- `未实现` —— 无代码，或只有数据表无逻辑
- `口径未定` —— 定义本身存在流派分歧或内部未裁决

## 九、多规则同时出现时的适用条件

### 9.1 月破 与 旺相 并存

| 项 | 内容 |
|---|---|
| 现象 | 同一爻既月破又旺/相，当前二者都计分（-3 与 +2 并存） |
| 规模 | 24576 / 294912（8.33%） |
| 待定 | 破爻是否强制降为不旺？古法「月破之爻如物已破」，理论上破即失气 |
| 状态 | `口径未定` |

### 9.2 暗动 与 月破 并存

T11：暗动+月破 1024 爻次。同一爻既被月建冲（破）又被日辰冲且旺（暗动），二者语义冲突。

`口径未定`。

### 9.3 休态日冲

`lingTai==='休'` 时既不标暗动也不标日破，只标「日冲（休态，暗动/日破待定）」，T11：2048 爻次。

古法只说「旺相为暗动、休囚为日破」，「休」既不在旺相也不在死囚。`口径未定`。

### 9.4 入墓的层级

只取月建/日辰为墓。动化墓（T9 12288）、变爻墓均未纳入。`口径未定`。

### 9.5 回头生权重不对称

用神侧 +2 / 世爻侧 +1。同一事实不同权重，是否属重复计分的另一种形态。`口径未定`。

### 9.6 多用神域取首

事业（官鬼+父母）、疾病（官鬼+子孙）、考试（父母+官鬼）只取第一个用神算原忌仇。`口径未定`。

### 9.7 六冲/六合卦名单

见 7.2 / 7.3。**这是唯一的「确定错误」而非「口径分歧」，优先级最高。**
