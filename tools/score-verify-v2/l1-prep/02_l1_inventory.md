## A3 · 已实现但存在已知缺陷

### A3-1 【确定错误】verdict.js 六冲卦名单缺 2 个

```js
// app/js/verdict.js:35
const LIU_CHONG_GUA = ['乾为天','坤为地','坎为水','离为火','震为雷','艮为山','巽为风','兑为泽'];
```

独立核对（古法定义：初四/二五/三上两两相冲）得 **10 个**，`constants.ts` 也是 10 个，verdict 只有 8 个。

缺：**天雷无妄、雷天大壮**。

影响：`love` 域「本卦六冲卦 -1」、`people` 域「六冲卦 -1」对这两卦不触发。

证据：T2 输出 `独立/constants/verdict: 10 / 10 / 8`，`verdict 缺: 天雷无妄、雷天大壮`。

### A3-2 【确定错误】verdict.js 六合卦名单错 3 个

```js
// app/js/verdict.js:36
const LIU_HE_GUA = ['地天泰','雷地豫','火地晋','水泽节','山雷颐','地雷复','泽水困','地泽临'];
```

独立核对得 8 个：`地天泰、地雷复、天地否、山火贲、水泽节、泽水困、火山旅、雷地豫`。

| 方向 | 卦名 |
|---|---|
| verdict 缺 | 天地否、山火贲、火山旅 |
| verdict 多（误列） | 地泽临、山雷颐、火地晋 |

影响：`love` 域「本卦六合卦 +1 / 六冲变六合 +2 / 六合变六冲 -2」在 6 个卦上判定错误（3 个漏加、3 个误加）。

证据：T3 输出 `独立/constants/verdict: 8 / 8 / 8`，但集合不同。

### A3-3 【已知缺陷】旺/相与月破并存

T11：`旺/相 与 月破并存 24576 / 294912`（8.33%）。

古法：爻被月建冲即为月破，破爻不当言旺。当前实现 `lingTai`（按五行比和判旺）与 `yuePo`（按地支相冲判破）互不影响，可同时为真。

MEMORY 已记录「丑月月破与旺相并存 1 例」导致评分反转。

### A3-4 【已知缺陷】入墓双计

用神持世且入墓时，`一、用神本体` 计 -1，`三、世爻自身` 又计 -1（`st.ruMu` 未纳入 `yongIsShi` 去重）。MEMORY 记录「戌月入墓双计 6 例」。

## A6 · 一句话总结

- **基础事实层（L0）已扎实**：八卦、世应、月令五态、六神、旬空五项独立核对全 0 差异，L0 两项修复确认生效。
