## 2. 语义分析：被怀疑的规则，到底重不重复？

这是本次最关键的纠正。审计报告原说"父母持世的『相于月+2』『帝旺+1』『世爻相于月+1』是同一因素数三次"。
逐条核对数据来源后（`wangshuai.ts`），结论是：

| 规则 | 它实际在算什么 | 数据来源 | 在你这卦里 | 是否重复 |
|---|---|---|---|---|
| 用神·得月令之气(相于月) +2 | 用神这一爻的旺气 | **对月建**的旺相休囚死 | 申金在戌月＝相 | 与"世爻相于月"**是同一事实**（因为用神持世） |
| 用神·临帝旺 +1 | 用神在十二长生宫的位置 | **对月建 OR 对辰（日辰）取** | 申金对月建戌是「衰」，**帝旺实际来自日辰酉** | **独立证据**：它反映的是日辰扶旺，不是月令旺相 |
| 世爻·相于月 +1 | 世爻的旺气 | 对月建 | 世爻就是持世的那个用神本身 | **重复**：和第一条是同一爻、同一月令状态 |

**所以你这卦的真相是**：三条里"用神相于月"和"世爻相于月"重复（持世导致同爻两算），而"帝旺"是日辰带来的另一条独立证据，**不该并**。
这正印证了你定的纪律：**不能因为规则涉及同一爻就判重复，也不能因为名字不同就判独立——要看数据来源和语义。**

按这个标准，三组问题归类如下：

### 问题 1：用神旺衰 ↔ 世爻旺衰
- **关系：条件性重复**。只有当**用神恰好持世**（yShi=true）时两者才是同一爻、同一状态；用神不持世时是两条独立证据（一管"事情本身"，一管"你自己"）。
- 处理：仅在持世时归组，保留"用神"侧（事），折掉重复的"世爻"侧。**安全**。

### 问题 2：世应相冲 ↔ 六冲卦（占婚）
- **关系：结构性重复（已实测证明）**。枚举八个六纯卦，世应**8/8 固定相冲**（乾世戌应辰、坤世酉应卯……无一例外）。所以六冲卦那条 -1 永远伴随世应相冲 -2 出现，是同一卦象的两层表述。
- 反向（六合卦）则**不能无脑并**：八个六合卦里只有 5 个世应相合，另 3 个（火地晋、山雷颐、地泽临）世应既非合也非冲。**必须真共现才并**。
- 处理：冲侧无条件归组；合侧只在"世应合 + 六合卦"都出现时并。**安全**。

### 问题 3：官父双双旺动 ↔ 用神本体旺相
- **关系：相关但有独立传统含义，倾向保留**。
  - 本体旺相：回答"这一个用神有没有气"。
  - 双双旺动：回答"官（名分/职位）和父（文书/凭证）是否**同时发动、相生有情**"——这是功名成败里一个独立的格局条件（光一个旺不等于两个都动且相生）。
- 原报告把它算进重复，但按语义它更像"格局加成"，《增删卜易》论功名确实重"官父同旺、动而生合世"。
- 处理：**本次实验仍按"可归组"做了一版给你看影响面，但我的建议是不并、或大幅保留权重**，需古籍案例确认。

### ★ 实验中新发现（原报告未提）：用神回头克 ↔ 世爻回头克
- 当持世用神动而化回头克时，`verdict.js` 同时加：
  - "用神发动却被变爻回头克" -2
  - "世爻动化回头克" -2
- 全矩阵共现 **9342 条**。而"回头生"方向**共现 0 条**——因为代码里根本没写"世爻化回头生"这条。这种"克写了两遍、生只写一遍"的不对称，强烈提示回头克那 -2 是同一事件被算了两次。
- 但它是否该并、并多少，和问题 3 一样属于**需要专业判断的一类**，本阶段不擅自定。

### 3.2 档位迁移矩阵（原→新，单位：条）

**方案甲**（较刚，非黑即白）：
```
大吉→吉 3302   大凶→凶 3115   平→凶 1748   吉→平 1420
凶→平  1375   凶→大凶 1144   平→吉  784   吉→大吉 112

```

```

平→凶    48   凶→大凶    1
```

读法：
- 两方案都让分布向中间收拢（大吉少了、大凶也少了），符合"削掉虚高/虚低"的预期。
- **方案甲有 71 例从「吉」直接跳到「凶」**（跨 3 档），方案乙几乎没有这种剧烈翻转。
- 这 71 例全部是 love 域、雷地豫、同时归并了 shiwang+liuhegua 两组——下面第 4 节专门拆解，它恰恰是最有信息量的案例。

## 4. 最值得你看的一个案例：71 例「吉→凶」是什么

`mask=72` 雷地豫之天火同人，辰月占感情，原算法判 **吉(1分)**。它的命中信号：

```
+2  妻财（持世）得月令之气，旺于月
-2  妻财（持世）发动，被变爻回头克
-2  世爻动化回头克
+1  世爻旺于月
+1  世应相合
+1  六合卦，占婚最宜
```

原算法靠"旺相 +2、世爻旺 +1、世应合 +1、六合卦 +1"这一组**重复的正面分**，把两个"回头克 -2"勉强顶成了吉。
方案甲把重复的正面分并掉后，剩 **-1（凶）**——而这更符合古法直觉：**用神持世旺动却化回头克，是"事情看着好、一动就自己坏自己"的典型凶象**，不该被几句"关系合得来"冲抵。

但请注意：这个翻转同时动用了"世爻旺归组"和"六合卦归组"，而**真正决定凶性的那两个 -2（回头克双计）我在 A/B 里并没有动**。也就是说——
> 即便不修回头克，光是不再重复奖励旺相/卦象，结论就已经更合理了；但若再修回头克，这卦会更凶。
这 71 例因此成为"问题 3 / 回头克是否该并"最好的评审样本，建议拿它去对照古籍断例。

## 5. 哪些已确认、哪些需要专业判断、哪些纯属权重口味

按你的要求分三类：

### A. 已确认的重复计分（语义+数据双重证实，可安全修）
1. **用神旺衰 ↔ 世爻旺衰**：仅在**用神持世**时重复（占 22,528 条命中）。
2. **世应相冲 ↔ 六冲卦**（love）：八纯卦世应 8/8 必相冲（6,144 条命中）。
3. **世应相合 ↔ 六合卦**：仅当两者真共现时（3,840 条命中；已排除 3 个世应非合的六合卦）。

### B. 需要古法/专业判断才能决定是否累加（不建议现在改）
4. **官父双双旺动 ↔ 用神本体旺相**（问题3）：格局加成有独立传统含义，建议保留或轻折。
5. **用神回头克 ↔ 世爻回头克**（新发现，9,342 条）：高度疑似重复，但"事坏"与"自身受伤"在古法里可能确有两层意义，需断例确认。回头生侧 0 共现，是不对称的强旁证。
6. **长生 / 墓 / 绝 等十二宫状态 与 旺相休囚**：数据来源不同（十二宫 vs 月令五行态），本实验**当作独立证据全部保留**，未并。是否独立也建议专业确认。

### C. 纯粹的权重设计选择（没有对错，只是口味）
7. 折减系数 k：实验用 0.5 只是演示，**没有任何古籍依据指定某个数值**，不应在无依据时固化。
8. 方案甲"副信号置 0" vs 方案乙"折半"：甲干净但有 71 例跨档翻转，乙平滑但治标。真正上线的形态可以是"确认重复的用甲、相关独立的用乙"。

## 6. 两个方案的优缺点

| | 方案甲·证据归组 | 方案乙·权重折减 |
|---|---|---|
| 做法 | 识别同一基础因素，副信号不计分 | 规则都保留，相关副信号按系数折减 |
| 优点 | 语义最干净，分数=独立证据数；彻底消除虚高 | 改动小、平滑、跨档翻转极少、风险低 |
| 风险 | 较刚；若归组判错（把独立证据并了）会过度纠偏；71 例跨档 | 系数 k 是拍的，缺古籍依据；治标，重复仍在 |
| 适用 | A 类已确认重复 | 想保守过渡时 |

**我的建议（供你决策，不替你定）**：不是二选一，而是分两步——
- **第一步只修 A 类 3 项已确认重复**，且用"归组但保留主信号"的方式（即甲的判定 + 较克制的处置）；
- **B 类（问题3、回头克、十二宫）先冻结**，挑第 4 节那种典型卦，找《增删卜易》《卜筮正宗》对应断例做人工评审，确认古法到底算一个因素还是两个，再决定并不并；
- **C 类系数不写死**，等 B 类有结论后再定权重。

## 7. 仍然无法验证的事（必须讲明）

1. **穷举 4096×12 不能证明谁更准**——它证明的是"程序怎么变、哪些盘翻转、规则如何交互"。要证明准确性，需要一批**有明确古籍结论的真实卦例**做回归基准。
2. 实验只动了月令一个变量；日辰、性别、起卦时刻、旬空随日辰的变化没有全组合展开（日辰固定为酉）。重复计分的定性结论不依赖此，但具体盘数会随日辰变。
3. 健康/决策/合作等域 0 变化，不代表这些域没有别的问题（例如之前发现的健康"官鬼安静/发动"文案矛盾，属另一类，不在本次计分实验内）。
4. k=0.5 等任何具体数值都**没有古籍依据**，仅作敏感性演示。
