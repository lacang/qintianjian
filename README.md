## 三条设计铁律

1. **只排事实，不下断语**。盘面、经典原文、中性事类可以给；"你会怎样"、"必吉必凶" 不下。
2. **确定性优先**。同一输入 + 同一规则版本 = 字节级相同输出。注解是版本锁定的查表，不是生成。
3. **纯本地**。不联网、不调模型、无账号、无后端。一键复制把盘面材料带到外部 AI 是唯一的外发路径，且由人主动触发。
